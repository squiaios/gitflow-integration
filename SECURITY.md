# Security Policy

## Supported versions

Only the latest release, and the current state of `master`, receive security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/squiaios/gitflow-integration/security/advisories/new).

Include what you can of the following:

- the affected version or commit;
- the steps to reproduce, or a proof of concept;
- the impact you foresee.

This is a personal project maintained on a best-effort basis: expect an answer within a few days,
not a guaranteed response time. Once a fix is available, the advisory is published and the
reporter is credited unless they prefer to stay anonymous.
